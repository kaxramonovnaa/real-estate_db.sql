Real Estate Management System
A relational database project built with MySQL to manage real estate operations, including properties, owners, agents, clients, sales, rentals, and payments.
Project Overview
The system organizes real estate data and manages relationships between different entities. It demonstrates relational database design, SQL queries, and data management.
Database Features
• Property and district management
• Owners, agents, and clients
• Property types and amenities
• Appointments and favorites
• Sales and rental contracts
• Payments and customer reviews
Database Structure
The database contains 15 main tables:
districts, property_types, owners, agents, clients, properties, property_images, amenities, property_amenities, appointments, sales, rent_contracts, payments, favorites, and reviews.

How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download real_estate_db.sql from this repository.
3. Open MySQL Workbench.
4. Import or execute the SQL script.
5. Explore the database and run SQL queries.
