# Real Estate Management System

A relational database project built with **MySQL** to manage real estate operations.

## 📌 Project Overview

This project manages:
- Properties
- Owners and agents
- Clients
- Sales and rentals
- Payments
- Customer reviews

## 🗄️ Database Structure

The database contains 15 main tables:

- districts
- property_types
- owners
- agents
- clients
- properties
- property_images
- amenities
- property_amenities
- appointments
- sales
- rent_contracts
- payments
- favorites
- reviews

## 🛠️ Technologies
